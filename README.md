# Coach AI Sales Trainer

Первая UI-заготовка тренажёра продаж.

## Запуск локально
Откройте `index.html` в браузере. Это демонстрационный интерфейс: пока без настоящего голосового ИИ, авторизации и сохранения результатов на сервере.

## Следующие этапы
1. Подключить голосовой диалог и серверный API.
2. Добавить вход сотрудников и роли руководителя.
3. Подключить базу данных для истории и оценок.
4. Перенести проект на облачную платформу.

## Важно
Не добавляйте реальные транскрибации, персональные данные сотрудников, API-ключи и пароли в публичный репозиторий.
