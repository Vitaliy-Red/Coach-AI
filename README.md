# Coach AI — первая рабочая версия тренажёра (MVP)

## Что уже работает в этой версии
- 15 сценариев возражений, подготовленных по материалам отчёта «Анализ звонков 224».
- Реалистичные стартовые реплики работодателей, цели тренировки, уточняющие вопросы и варианты следующего шага.
- Ролевая тренировка в браузере: менеджер отвечает текстом или голосовым вводом (если браузер поддерживает Web Speech API).
- Озвучивание реплик работодателя средствами браузера.
- Автоматическая оценка 0–100 по четырём критериям: признание позиции, выяснение причины, предложение решения и фиксация следующего шага.
- Личный журнал тренировок для выбранного сотрудника, сводная аналитика на этом устройстве и экспорт CSV.

## Как обновить сайт на Cloudflare Pages через GitHub
1. Скачайте и распакуйте архив.
2. В репозитории GitHub `Coach-AI` замените `index.html`, `README.md` и папку `src` файлами из архива. Не загружайте архив ZIP как один файл.
3. Создайте commit в ветке `main`.
4. Cloudflare Pages автоматически соберёт и опубликует обновление.

Настройки Cloudflare Pages для этой статической версии:
- Framework preset: `None`
- Build command: оставить пустым
- Build output directory: `.` (корень репозитория)
- Root directory: оставить пустым (корень репозитория)

## Важные ограничения этой версии
Это первая клиентская версия (MVP), а не полностью готовая корпоративная система:
- Ролевые ответы пока формируются сценарными правилами, а не подключённой большой языковой моделью.
- Оценка автоматическая по текстовым признакам и требует проверки на реальных диалогах; она не заменяет экспертную оценку руководителя.
- История хранится в `localStorage` браузера. Она не синхронизируется между устройствами и не является общей базой отдела.
- Нет серверной авторизации, отдельных прав сотрудника и руководителя, общей базы данных и централизованного хранения результатов.
- Голосовой ввод зависит от браузера и его поддержки Web Speech API; для полноценного голосового ИИ с естественным диалогом понадобится серверный API и подключение модели.

Для корпоративной версии следующим этапом нужно подключить Cloudflare Pages Functions/Workers, базу данных (например, D1), авторизацию и голосовую/LLM-модель. Ключи API следует хранить только в секретах Cloudflare, не в GitHub и не в браузерном коде.

## Безопасность данных
Не добавляйте в публичный репозиторий реальные транскрибации, персональные данные сотрудников, записи звонков, пароли или API-ключи. Отчёт и исходные звонки должны храниться отдельно с ограниченным доступом.
