# Red Coach

Тренажёр звонков рекрутерам действующих клиентов. В каталоге есть разговоры о подборе, сервисе и продлении, а также отдельное упражнение на поиск ответственного за подбор. [Карта сценариев](docs/Сценарии.md) показывает, что менеджер должен выяснить и к чему прийти в каждом звонке.

## Как устроен рабочий сайт

- **Голос.** Браузер подключается к Cloudflare Pages, затем Render передаёт аудио в Gemini Live. При сбое можно продолжить голосом браузера или в «Диалоге».
- **Диалог и разбор.** Cloudflare Workers AI отвечает текстом и оценивает четыре критерия. Вариант с голосом браузера озвучивает эти же ответы.
- **Фразы.** Ответ отправляется в Cloudflare D1. Следующая реплика появляется после подтверждения записи. Повтор сохранения обновляет ответ на том же шаге.
- **Мои результаты.** Хранятся в браузере отдельно для каждого профиля. Руководитель видит данные D1 в «Аналитике».

## Развёртывание

Cloudflare Pages подключается к этому репозиторию и собирает ветку `main`. Каталог результатов сборки — корень репозитория. Серверные функции находятся в `functions/`.

| Параметр | Рабочее значение |
|---|---|
| `PROVIDER` | `gemini` |
| `VOICE_ENGINE` | `realtime` |
| `GEMINI_BRIDGE_URL` | URL голосового сервера на Render |
| Привязка Workers AI | `AI` для диалога, резервного голоса и разбора |
| Привязка Cloudflare D1 | `DB` для результатов и ответов |
| `STAFF_CONFIG` | Secret с полями `signingKey` (64 шестнадцатеричных символа), `teams` и `leaders` |
| `ADMIN_CODE` | Дополнительный код «Аналитики», если задан |
| `ACCESS_CODE` | Общий код команды, если задан |

Сотрудники входят по личному коду. Список имён до входа не показывается. Сессия действует восемь часов. Состав команд и ключ подписи хранятся в Cloudflare как Secret. Для выдачи личных кодов администратор с доступом к секрету вычисляет `staffCode` для записей, которые возвращает `staffProfiles` из `functions/_lib/staff-auth.js`. Коды передаются каждому сотруднику отдельно. Смена секрета отзывает выданные коды и сессии.

На новом домене «Аналитика» требует настроенный доступ. Список ролей берётся из `STAFF_CONFIG`. Желательно проверять новые привязки по `/api/config` после развёртывания. На старом адресе сброс личной истории срабатывает, когда браузер загрузит текущую версию сайта.

## Проверки

В Node.js с `node:sqlite` запустите `node --test tests/*.test.mjs`. Тесты используют временную базу и синтетические данные. Для нового сценария добавьте карточку в `assets/js/catalog.js`, легенду в `functions/_lib/private.js` и конкретные признаки выявленной потребности в `functions/_lib/prompt.js`.
