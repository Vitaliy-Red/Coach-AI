# Coach AI — пилотная версия 2

## Что изменено
- Визуальная система приведена к брендбуку SuperJob: палитра `#FFFFFF`, `#3E3E3E`, `#E3E7EB`, `#D40E1E`, `#00AA6D`, `#00744A`, `#D1FFF1`; без декоративных теней.
- Тренировка начинается с естественного телефонного приветствия «Алло, да, слушаю вас», а не с готового возражения.
- Добавлен голосовой режим: распознавание речи браузером, автоматическая передача реплики в диалог и озвучивание ответов клиента.
- Сохранён текстовый резервный режим.
- Система оценки следует четырём критериям отчёта: принял жалобу, отработал возражение, предложил альтернативу, шаг со сроком. Каждый критерий — 25 баллов.
- Исправлены значения ключевых частот по листу «Возражения» отчёта на 224 звонка: HH — 73 (32,6%), мало откликов — 50 (22,3%), дорого — 27 (12,1%), 124 из 156 возражений закрыты частично или не отработаны (79%).

## Как запустить
Это статический сайт. Откройте `index.html` локально или опубликуйте содержимое архива в корне GitHub-репозитория, подключённого к Cloudflare Pages.

## Важно для пилотного теста
- Для голосового режима используйте актуальный Google Chrome или Microsoft Edge, откройте сайт по HTTPS и разрешите доступ к микрофону.
- Распознавание речи выполняется средствами браузера. В браузере без Web Speech API используйте текстовый резервный режим.
- В этой пилотной версии клиент отвечает по встроенным сценарным правилам, а не через подключённую облачную LLM. Это позволяет проверить поток тренировки сегодня, но диалог ещё не обладает полноценной генеративной гибкостью Claude/ChatGPT.
- Оценка предварительная и основана на проверке маркеров в распознанном тексте. Это не экспертная оценка смысла и качества речи.
- Результаты и список сотрудников хранятся локально в браузере (`localStorage`). Между компьютерами и сотрудниками они не синхронизируются. Для корпоративного запуска потребуются авторизация, серверная БД и подключение LLM.
- Выбор имени сотрудника в этой версии — тестовый переключатель, не система авторизации.

## Публикация
При загрузке файлов в GitHub сохраняйте структуру:
- `index.html`
- `src/app.js`
- `src/styles.css`

Cloudflare Pages автоматически опубликует коммит из production-ветки.
