# Coach AI — голосовой тренажёр звонков SuperJob

Менеджер выбирает тренажёр, звонит клиенту голосом и получает разбор звонка.
Клиента играет ИИ: по легенде и **реальным фразам клиентов** из 222 расшифровок звонков SuperJob.
Разбор идёт по методике анализа 224 звонков: 4 критерия, главная ошибка, «как надо сказать».

## Как устроено

```
Браузер менеджера ──микрофон──► /api/realtime ──► голосовая модель (Yandex AI Studio или OpenAI Realtime)
        ▲                       (реле на Cloudflare: ключ и промпт клиента остаются на сервере)
        └──────голос клиента────────────┘
После звонка: расшифровка ──► /api/evaluate ──► текстовая модель ──► разбор 0–4
Без микрофона: текстовый режим ──► /api/chat
```

- `index.html`, `assets/` — сайт (каталог → бриф → звонок → разбор → мои результаты).
- `assets/js/catalog.js` — публичная часть тренажёров: что менеджер видит до звонка.
- `functions/_lib/private.js` — скрытая часть: легенда клиента, возражения, реальные фразы, что смягчает и что раздражает.
- `functions/_lib/prompt.js` — промпт клиента (по `docs/Промпт_средний_клиент.md`) и промпт разбора.
- `functions/api/*` — серверные функции Cloudflare Pages.

## Запуск: что нужно сделать один раз

### 1. Выбрать голосовую модель

| | Yandex AI Studio (рекомендую) | OpenAI Realtime |
|---|---|---|
| Работает из России | да | нет, официально Россия не поддерживается |
| Оплата | рубли, договор с Яндекс Облаком | зарубежная карта |
| Голос | голоса SpeechKit (masha, kirill и др.) | как в ChatGPT (marin, cedar) |

Оба варианта работают по одному протоколу (OpenAI Realtime), код один и тот же — меняются только переменные.

### 2. Получить ключ

**Yandex AI Studio**
1. Откройте AI Studio в нужном каталоге Yandex Cloud и скопируйте ID каталога.
2. Нажмите «Создать API-ключ»: AI Studio сама создаст сервисный аккаунт с ролью `ai.editor` и ключ с доступом к моделям и речи.
3. Сохраните секретную часть ключа — она показывается один раз.

**OpenAI** — ключ на platform.openai.com с доступом к Realtime API.

### 3. Прописать переменные в Cloudflare

Cloudflare → Workers & Pages → `superjob-coach` → Settings → Variables and Secrets → Production:

| Переменная | Значение | Тип |
|---|---|---|
| `PROVIDER` | `yandex` или `openai` | текст |
| `YANDEX_API_KEY` | API-ключ сервисного аккаунта | **Secret** |
| `YANDEX_FOLDER_ID` | ID каталога | текст |
| `OPENAI_API_KEY` | ключ OpenAI (если выбран OpenAI) | **Secret** |
| `ACCESS_CODE` | код команды, например `sj-2026` | **Secret** |
| `ADMIN_CODE` | код для вкладок «Руководитель» и «Аналитика» | **Secret** |

`ACCESS_CODE` обязателен на практике: сайт публичный, а каждый звонок стоит денег. Код вводится один раз и запоминается в браузере.
`ADMIN_CODE` закрывает бюджет и аналитику от менеджеров. Пока он не задан, вкладки открыты всем. После 10 неверных попыток с одного адреса вход закрывается на 15 минут.

**Руководители** входят через «Кто вы?» → «Я руководитель» → своё имя → код `ADMIN_CODE` (один раз на компьютере). Вкладки «Аналитика» и «Руководитель» видны только им. Список руководителей — `LEADERS` в `functions/_lib/team.js`.

**База для учёта расходов и аналитики:** Settings → Bindings → D1 database, имя привязки `DB`, база `coach-ai-db`. Таблицы создаются сами при первом звонке.

После сохранения переменных сделайте новый деплой: Deployments → последний деплой → Retry deployment.

### 4. Проверить

Откройте сайт → любой тренажёр → «Позвонить клиенту». Браузер спросит доступ к микрофону.
Клиент снимает трубку сам («Алло?»). Перебивать можно. Звонок завершается кнопкой или когда клиент прощается.

## Режимы тренировки

- **Диалог** (по умолчанию). Клиента играет ИИ по портрету из `functions/_lib/private.js`: легенда, возражения, реальные фразы. Клиент отвечает текстом на то, что сказал менеджер. Менеджер отвечает голосом: кнопка микрофона рядом с полем, речь в текст переводит браузер (Chrome, Edge). Можно печатать. Нужна текстовая модель (YandexGPT).
- **Голос.** Звонок голосом, как по телефону. Нужна голосовая модель.
- **Фразы** (работает без ИИ). Реальные фразы клиента по одной, на ваши ответы они не реагируют. Первая — клиент снимает трубку, дальше 6, 10 или все фразы в случайной выборке. Каждый ответ пишется в базу (таблица `answers`). Руководитель видит ответы в «Аналитике» по фразам клиента и выгружает CSV.

Если в браузере нет распознавания речи, подойдёт диктовка системы (Windows: Win + H).

## Необязательные настройки

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `REALTIME_MODEL` | голосовая модель | Yandex: `gpt://<каталог>/speech-realtime-250923`, OpenAI: `gpt-realtime-2.1` |
| `LLM_MODEL` | модель текстового режима | Yandex: `yandexgpt/latest`, OpenAI: `gpt-4.1-mini` |
| `EVAL_MODEL` | модель разбора | Yandex: `yandexgpt/latest`, OpenAI: `gpt-4.1` |
| `VOICE_FEMALE`, `VOICE_MALE` | голоса клиента | Yandex: `masha` / `kirill`, OpenAI: `marin` / `cedar` |
| `VOICE_ROLE` | амплуа голоса Yandex (`neutral`, `strict` и др.) | не задано |
| `YANDEX_TRANSCRIPTION` | `1` — явно включить расшифровку речи менеджера в Yandex | выкл. |
| `AUDIO_RATE` | частота звука для Yandex | `16000` |
| `MAX_CALL_SECONDS` | предел длительности звонка | `900` |
| `BUDGET_RUB` | бюджет на вкладке «Руководитель» (можно менять и на самой вкладке) | `4000` |
| `PRICE_AUDIO_IN_SEC`, `PRICE_AUDIO_OUT_SEC` | ₽ за секунду звука от менеджера / от клиента | `0.0264` / `0.0203` |
| `PRICE_RT_IN_1K`, `PRICE_RT_CACHED_1K`, `PRICE_RT_OUT_1K` | ₽ за 1000 токенов голосовой модели | `0.3` / `0.075` / `0.5` |
| `PRICE_LLM_IN_1K`, `PRICE_LLM_OUT_1K` | ₽ за 1000 токенов текстовой модели и разбора | `1.2` / `1.2` |

Если в разборе нет ваших реплик, включите `YANDEX_TRANSCRIPTION=1`. Для страховки браузер (Chrome, Edge, Яндекс Браузер) параллельно расшифровывает речь менеджера сам.

## Важно

- **Сделайте репозиторий приватным** (GitHub → Settings → Change visibility). В нём легенды клиентов и реплики из звонков компании. Cloudflare Pages работает с приватным репозиторием.
- **Доступ из России.** С 2025 года часть российских провайдеров замедляет сайты на Cloudflare. Если у менеджеров сайт открывается нестабильно, следующий шаг — перенести сайт и реле в Yandex Cloud (статика в Object Storage, реле — в Serverless Containers).
- **Гарнитура.** С наушниками клиент не слышит сам себя из динамиков и не перебивает сам себя.
- **Результаты** менеджер видит в «Мои результаты» (хранятся в браузере, выгрузка CSV). Руководитель видит все тренировки во вкладке «Аналитика» по группам СМБ 1, СМБ 2, Тёплые клиенты и Хантеры. Состав групп — `functions/_lib/team.js`.
- **Расход на сайте — оценка** по тарифам Yandex AI Studio и замеренным секундам и токенам. Точная сумма — в биллинге Yandex Cloud. Там же поставьте уведомление о бюджете.
- Без ключей сайт работает в режиме просмотра: тренажёры видны, кнопка звонка неактивна и показывает, каких настроек не хватает.

## Как добавить или поменять тренажёр

1. `assets/js/catalog.js` — добавьте карточку: `id`, название, кому звоним, что известно до звонка, цель, реальная фраза.
2. `functions/_lib/private.js` — под тем же `id`: легенда, возражения (по порядку важности), реальные фразы клиентов, что смягчает, что раздражает.
3. Фразы берите из расшифровок дословно, без имён, телефонов и названий компаний.
