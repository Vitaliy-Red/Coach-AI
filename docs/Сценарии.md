Каждый тренажёр — реальная ситуация из звонков SuperJob. Клиент говорит фразами из расшифровок
(139 реплик, лёгкая правка распознавания, без имён и названий компаний), легенда собрана из тех же звонков.

## Как клиент себя ведёт

Правила поведения — из `docs/Промпт_средний_клиент.md`: занятой и скептичный, отмахивается,
причину называет только на открытый вопрос, не верит лозунгам, верит цифрам по своей профессии.
Интерес растёт, когда менеджер выясняет причину, отвечает конкретикой, предлагает малый шаг под ситуацию
и называет дату следующего контакта. Итог звонка выбирается по реальным частотам:
КП на почту 43%, отказ 22%, перенос на дату 16%, тест 10%, оплата 9%.

## Сложность

- Лёгкий — одно возражение, клиент решает сам.
- Средний — два возражения, причина только на вопрос.
- Трудный — все возражения, плохой прошлый опыт, решает не клиент, потолок бюджета ниже.

## Разбор

4 критерия по 0 или 1: принял жалобу, отработал возражение, предложил альтернативу, шаг со сроком.
Без претензии засчитываются первые три, оценивается только шаг со сроком.
Главная ошибка — одна из пяти: нет доказательств, ушёл от возражения, давил или спорил, нет следующего шага, не знал условий и цифр.
